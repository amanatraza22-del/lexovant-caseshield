# Lexovant CaseShield

A prototype for litigation file organisation,
evidence traceability and rule-based review leads.

## Features
- Matter dashboard
- Fact and evidence map
- Chronology
- Repeated-amount review flags
- Lawyer review checklist
- CSV export

## Run locally
1. Install Python 3.10 or newer.
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open http://127.0.0.1:5000

## Limitations
This prototype does not use an AI model, read PDFs,
authenticate users, or provide legal conclusions.
All review leads must be independently verified by a lawyer.
Use fictional data only.
